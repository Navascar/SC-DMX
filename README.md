# SC DMX

Застосунок для керування RGB-прожекторами (PAR, LED-панелі, стробоскопи тощо) через DMX512.
Сервер на Python шле DMX у USB-інтерфейс або в мережу. Керувати можна з браузера на ПК, планшеті чи телефоні в тій самій мережі.

## Можливості

- **DMX-інтерфейси:**
  - **uDMX** (Anyma та клони) — інтерфейс за замовчуванням;
  - Enttec DMX USB Pro і сумісні (DMXking ultraDMX Pro та ін.);
  - Open DMX / будь-який USB-RS485 на FTDI;
  - Art-Net;
  - sACN (E1.31);
  - симулятор без обладнання.
- **Патч приладів:** назва, DMX-адреса, профіль каналів. Можна додати кілька однакових прожекторів, вони отримають послідовні адреси. Застосунок попереджає, якщо адреси приладів перетинаються.
- **Профілі каналів:** вбудовані RGB, RGBW, Dim+RGB, Dim+RGB+Strobe, RGBWA+UV та інші. Можна створити власний профіль з ролями `r g b w a uv dim strobe zero full`.
- **Статичні кольори:** 13 готових кнопок, серед них теплий, звичайний і холодний білий. На RGBW-приладах білі кольори використовують W-канал. Клік заливає кольором вибрані прилади (або всі, якщо нічого не вибрано) і зупиняє на них ефект. Гарячі клавіші `1`–`9`. Можна зберегти власний колір, видалити непотрібні або повернути стандартний набір.
- **Очищення кольорів:** велика кнопка «Очистити» у верхній панелі (або Delete / 0) гасить вибрані прилади чи сегменти, а якщо нічого не вибрано, то все. Ефект на них зупиняється.
- **LED-бари з сегментами:** кожному сегменту можна задати окремий колір кліком по ньому на плитці приладу. Ефекти біжать уздовж бару, якщо увімкнено «по сегментах».
- **Керування мишею:** клік вибирає прилад, Shift + клік — кілька. Ctrl+A вибирає всі прилади, Ctrl+Z скасовує дію, Ctrl+Y повторює. Подвійний клік відкриває властивості приладу. Правий клік відкриває контекстне меню, вміст якого залежить від панелі: прилади, колір, статичні кольори, ефекти чи сцени.
- **Пресети LED-барів:** якщо вибрано бар, кнопка «▦ Пресети» відкриває окреме вікно з 25 вбудованими програмами. Для профілів WASH 243 пресети вмикаються автоматично, для інших приладів — галочкою у властивостях.
- **Точні значення:** клік по числу біля повзунка дозволяє вписати значення з клавіатури.
- **Колір:** колірне коло, палітра, окремі слайдери R/G/B/W/Amber/UV, диммер і канал стробу. Показуються лише ті слайдери, які є у вибраних приладів.
- **Майстер-диммер і BLACKOUT** (гаряча клавіша `B`). Під час Blackout усі канали дорівнюють 0.
- **Ефекти:** веселка, плавна зміна кольорів, біжучий вогонь, пульсація, стробоскоп, випадкові кольори, вогонь. Для ефектів налаштовуються швидкість, розкид фази між приладами і власна палітра.
- **Сцени:** збереження й виклик з плавним переходом (кросфейдом). Сцену можна зберегти разом з ефектом.
- **DMX-монітор** на всі 512 каналів і живе превʼю кольору кожного прожектора.
- Конфігурація автоматично зберігається в `config.json`.

## Встановлення (Windows)

Потрібен Python 3.10+. Якщо його немає, інсталятор спробує поставити Python через winget.

**Варіант 1: одна команда.** Відкрийте PowerShell і виконайте:

```powershell
$s = irm https://raw.githubusercontent.com/Navascar/SC-DMX/main/install.ps1; iex $s.TrimStart([char]0xFEFF)
```

**Варіант 2: архів.** Завантажте `SC-DMX.zip` з [Releases](https://github.com/Navascar/SC-DMX/releases/latest), розпакуйте його і запустіть `install.bat`.

Що робить інсталятор:
- копіює програму в `%LOCALAPPDATA%\SC-DMX`;
- створює окреме середовище Python і ставить залежності;
- додає ярлики **SC DMX** на робочий стіл і в меню «Пуск»;
- перевіряє uDMX;
- запускає програму.

Програма відкривається у власному вікні, без консолі. Вікно побудоване на вбудованому рушії (Qt WebEngine): Edge чи інший браузер не потрібен, і **інтернет для роботи не потрібен**. Він потрібен лише для перевірки й завантаження оновлень. Прожектори світять, лише поки вікно відкрите. Закриття вікна (хрестик або Alt+F4) потребує підтвердження. Після нього програма гасить світло й повністю завершується, у фоні нічого не лишається. Якщо програма вже працює, ярлик просто відкриє її вікно.

Видалення: `uninstall.bat` у теці програми.

## Робота без інтернету

Усе, що потрібно для роботи, встановлюється разом із програмою: інтерфейс, драйвер uDMX (libusb) і вікно (Qt WebEngine, ~250 МБ під час першого встановлення). Без мережі програма працює повністю. Перевірка оновлень у цей час просто відкладається, і програма повторює її кожні 10 хвилин, доки не з'явиться мережа.

## Оновлення

Програма сама перевіряє [GitHub Releases](https://github.com/Navascar/SC-DMX/releases): під час запуску і далі щогодини. Якщо вийшла нова версія, у верхній панелі зʼявляється зелена кнопка **«⬆ Оновити до …»**. Вона відкриває список змін і кнопку **«Встановити оновлення»**.

Після натискання програма:
1. завантажує нову версію;
2. замінює свої файли (стара копія лишається в `.update-backup`);
3. доставляє нові залежності;
4. перезапускається приблизно за 10 секунд.

Сторінка перезавантажиться сама. Налаштування, патч, сцени й кольори з `config.json` зберігаються, а світло під час оновлення не гасне.

Перевірити оновлення вручну можна в **⚙ Налаштування → Про програму**.

### Як випустити нову версію (для розробника)

1. Внесіть зміни.
2. Підвищте `__version__` у `dmxctl/__init__.py`, наприклад `1.0.0 → 1.1.0`.
3. Додайте розділ `## 1.1.0` у `CHANGELOG.md`. Його текст стане описом релізу і буде показаний у «Що нового».
4. Зробіть `git push` у `main`.

GitHub Actions проганяє тести, створює реліз `v1.1.0` з архівом `SC-DMX.zip`, і всі встановлені програми запропонують оновитися.

## Запуск вручну (Linux / macOS / розробка)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m dmxctl --open          # лаунчер з автоперезапуском після оновлень
python -m dmxctl.server -v       # лише сервер, без лаунчера
python -m dmxctl --check         # перевірити підключення uDMX
```

Параметри: `--port 8080`, `--host 0.0.0.0`, `--config шлях/до/config.json`, `--background` (не вимикатися після закриття вікна, наприклад для керування лише з телефона). Інтерфейс доступний за адресою http://localhost:8080, а з телефона в тій самій мережі — за `http://<IP-компʼютера>:8080`.

Linux: щоб отримати доступ до USB, див. правило udev нижче. Автооновлення вимикається в git-копії; там оновлюйтесь командою `git pull`.

## Підключення uDMX

uDMX не створює COM-порт: застосунок працює з ним напряму через libusb (бібліотеки `pyusb` і `libusb-package` ставляться з `requirements.txt`).

### Windows — драйвер WinUSB (один раз)

1. Підключіть uDMX і завантажте **Zadig**: https://zadig.akeo.ie
2. Запустіть Zadig, виберіть у меню **Options → List All Devices**.
3. У списку виберіть **uDMX** (USB ID `16C0 05DC`).
4. Праворуч виберіть драйвер **WinUSB** і натисніть **Install Driver** / **Replace Driver**.
5. Програма підхопить адаптер сама. Перевірити можна так: `%LOCALAPPDATA%\SC-DMX\.venv\Scripts\python -m dmxctl --check`.

> Якщо для uDMX уже встановлено драйвер libusb-win32 (наприклад, разом із QLC+), застосунок спробує працювати і через нього. Якщо `--check` пише, що відправка не вдалася, замініть драйвер на WinUSB. QLC+ 4.12+ теж працює з WinUSB.

### Linux — права доступу

```bash
echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="16c0", ATTR{idProduct}=="05dc", MODE="0666"' | sudo tee /etc/udev/rules.d/50-udmx.rules
sudo udevadm control --reload-rules && sudo udevadm trigger
```

### Типові проблеми

| Повідомлення | Що робити |
|---|---|
| `uDMX не знайдено` | Перевірте кабель/порт; у Windows встановіть WinUSB через Zadig. |
| `не знайдено бібліотеку libusb` | Запустіть `install.bat` ще раз. |
| пристрій знайдено, але відправка не вдалася | Не той драйвер — замініть на WinUSB у Zadig. |
| прилади не реагують, хоча статус «працює» | Перевірте адресу й DMX-режим на прожекторі, кабель DMX і термінатор 120 Ом на останньому приладі. |

## Бібліотека приладів

У вікні «Новий прилад» є пошук по вбудованій бібліотеці з **1295 моделей** від 300+ виробників: Chauvet, American DJ, Eurolite, Stairville, Showtec, Cameo, Varytec, beamZ, Briteq та інших. Це **4405 режимів DMX**. Введіть виробника чи модель, клікніть потрібний режим, і профіль каналів створиться сам. Бібліотека працює без інтернету.

Описи взято з відкритих баз [Open Fixture Library](https://open-fixture-library.org) (MIT) і [QLC+](https://github.com/mcallegari/qlcplus) (Apache-2.0). Під час перетворення програма застосовує безпечні правила:
- канали кольорів (RGBWA+UV) і диммера керуються з програми;
- строб або затвор ставиться на «відкрито»;
- макроси, програми й рух голови — на «без функції»;
- пікселі LED-барів стають сегментами.

Оновити бібліотеку з нових версій баз можна так: `python tools/build_library.py --ofl <open-fixture-library>/fixtures --qlc <qlcplus>/resources/fixtures`.

## Free Color WASH 243

Профілі складено за інструкцією виробника. Режим вибирається на самому барі кнопками UP/DOWN, і дисплей показує його код. Той самий режим треба вибрати в програмі як профіль.

| Код на барі | Профіль у програмі | Каналів | Що дає |
|---|---|---|---|
| P001 | 24 кан. P001 (8 сегментів) | 24 | 8 незалежних RGB-сегментів — найкраще для ефектів програми |
| L001 | 12 кан. L001 (4 сегменти) | 12 | 4 сегменти |
| H001 | 8 кан. H001 | 8 | диммер, строб, вбудовані програми + швидкість, RGB |
| E001 | 6 кан. E001 (2 сегменти) | 6 | 2 половини бару |
| d001 | 4 кан. d001 (Dim+RGB) | 4 | загальний диммер + один колір |
| C001 | 3 кан. C001 (RGB) | 3 | один колір |
| A001 | 2 кан. A001 (програми) | 2 | лише вбудовані програми + швидкість |

**Пресети (вбудовані програми).** Клік по бару замінює панель «Колір» пресетами: 23 програми бару: 7 кольорів, 9 ефектів, 6 градієнтів і «Від звуку». Там же є повзунок швидкості. У режимах A001 і H001 програма йде у свій канал (CH1 або CH3), а швидкість — у CH2 або CH4.

Якщо бар реагує лише на «червоний» і перемикає програми «яскравістю», він стоїть у режимі A001, а в програмі вибрано RGB-профіль. Виберіть профіль «2 кан. A001» у властивостях бару (подвійний клік) або переключіть бар у режим P001.

Кілька барів одного режиму можна додати разом: поле «Кількість» дає їм послідовні адреси.

## Швидкий старт

1. **⚙ Налаштування → DMX-вихід:** за замовчуванням вибрано uDMX — застосунок сам знайде адаптер (кнопка «Знайти» шукає повторно). Індикатор зверху має стати зеленим. Інші інтерфейси (Enttec, Art-Net, sACN) теж доступні в цьому списку.
2. **Прилади:** натисніть «＋ Додати» в панелі «Прилади» і додайте свої. Стартова адреса і профіль мають збігатися з DIP-перемикачами або меню прожектора та його DMX-режимом (кількістю каналів).
3. Клікніть прилад, щоб вибрати його. Shift + клік додає до вибору ще прилади або сегменти. Далі задайте колір або запустіть ефект.

## Структура

```
dmxctl/
  outputs.py   — DMX-драйвери і формування пакетів (uDMX, Enttec Pro, Open DMX, Art-Net, sACN)
  fixtures.py  — прилади, профілі, рендер у всесвіт DMX
  effects.py   — ефекти
  engine.py    — рушій: стан, команди, сцени, кросфейд, збереження
  server.py    — aiohttp-сервер + WebSocket
  updater.py   — перевірка та встановлення оновлень з GitHub Releases
  __main__.py  — лаунчер: вікно застосунку, одна копія, перезапуск після оновлення
  static/      — веб-інтерфейс (HTML/CSS/JS без залежностей)
tests/         — тести
install.ps1    — інсталятор Windows (install.bat — запуск подвійним кліком)
.github/       — CI: тести та автоматичні релізи
```

Прилади

Клік — вибір одного приладу. Shift + клік — додати до вибору ще прилади. У приладів із сегментами клік по сегменту вибирає окремий сегмент. Подвійний клік — властивості приладу, правий клік — меню. Delete / 0 — очистити кольори.

для всіх приладів

Клік заливає кольором вибрані прилади (або всі, якщо нічого не вибрано) і зупиняє на них ефект.

Ефекти

Палітра

Порожня палітра — ефект бере власні кольори приладів (для пульсації, стробу, біжучого вогню).

Сцени

    DMX-монітор (512 каналів)

    Налаштування

    uDMX працює через libusb, а не через COM-порт. У Windows один раз встановіть драйвер WinUSB програмою Zadig (інструкція в README). Перевірка з консолі: python -m dmxctl --check

    Art-Net: всесвіт 0..32767 (Net·SubNet·Universe), порт 6454.

    sACN: всесвіт 1..63999. Без IP пакети йдуть на multicast 239.255.x.y.

    Open DMX потребує точних таймінгів — якщо прилади мерехтять, краще використати DMX USB Pro або Art-Net.

    НазваАдресаПрофільКанали

    Ролі каналів: r g b w a uv — кольори, dim — диммер, strobe — строб, zero — завжди 0, full — завжди 255. Порядок має відповідати інструкції до прожектора.
